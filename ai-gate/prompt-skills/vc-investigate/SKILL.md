# 조사만 하기 (수정 금지)

요청 내용: $ARGUMENTS
(비어 있거나 `$ARGUMENTS` 그대로 보이면 호출 메시지에서 이 스킬 이름 뒤의 내용을 요청으로 본다.)

이번 작업은 **조사만** 한다. 파일 수정, 브랜치 생성, 커밋은 하지 않는다(파이프라인 Node 1 의 "조사만 요청" 분기).

1. 프로젝트 문서(`CLAUDE.md`, `AGENTS.md` 등)와 빌드 설정을 읽는다.
2. 요청한 기능과 관련된 화면, 로직, 데이터 흐름을 실제 코드에서 따라간다(진입점 → 서비스 → 저장소/외부 연동).
3. 다음을 정리해 보고한다.
   - **관련 흐름:** 파일 경로:줄 번호와 함께 단계별로
   - **재사용할 수 있는 코드:** 이미 있는 유틸·컴포넌트·패턴
   - **수정해야 할 파일:** 파일마다 바꿀 내용 한 줄
   - **추천 방법:** 가장 작은 변경 1개와 이유. 대안이 있으면 한 줄로 비교
   - **낯선 용어:** 처음 보는 사람이 알아야 할 용어를 쉽게 설명
   - **미확인:** 코드로 확인하지 못한 내용(추측)을 따로 표시
4. 질문은 답에 따라 만드는 방식이 달라질 때만 최대 3개 한다.
5. 보고 후 멈춘다. 구현은 사용자가 따로 지시할 때 시작한다.
